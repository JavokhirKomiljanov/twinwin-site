2 · КОНВЕЙЕРPIPELINE

ИндексацияIngestion

Парсинг → разбиение на фрагменты → векторные представления → индекс. Очередь с повторами и dead-letter: сбой одного файла не роняет загрузку. Вместе с каждым документом фиксируется снимок прав доступа.Parse → chunk → embed → index. A retry queue with dead-letter handling: one bad file never kills the batch. Each document is stored with a snapshot of its access rights.

3 · ХРАНИЛИЩЕSTORAGE

База знанийKnowledge store

Postgres + pgvector для смыслового поиска, объектное хранилище для исходных файлов, Redis-очередь для конвейера. Проверенный, переносимый стек — без экзотики, которую некому поддерживать.Postgres + pgvector for semantic search, object storage for originals, Redis for the queue. A proven, portable stack — no exotic tech nobody can maintain.

4 · RAG

Движок ответовAnswer engine

Гибридный поиск (смысл + ключевые слова) отбирает топ-20 фрагментов → повторное ранжирование до топ-8 → лучшая AI-модель собирает ответ с цитатами → порог уверенности: мало оснований — честное «в базе этого нет».Hybrid search (semantic + keyword) picks top-20 chunks → reranked to top-8 → a best-in-class model writes a cited answer → confidence gate: weak evidence means an honest "not in the knowledge base."
